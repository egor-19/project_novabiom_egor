# Проект Novabiom

Учебное веб-приложение для учёта наборов на вымышленных данных.

## Что нужно для запуска

- Python 3.11 или новее
- Windows PowerShell для выполнения команд 

## Как запустить

Открыть PowerShell в папке проекта, где лежит app.py

1. Создать виртуальное окружение для проекта:
   ```
   py -m venv .venv
   ```
2. Установить зависимости из requirements.txt в это окружение:
   ```
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Запусти локальный сервер Flask:
   ```
   .\.venv\Scripts\python.exe -m flask --app app.py run
    ```

## Как проверить

Открой в браузере страрицу по адресу: http://127.0.0.1:5000 
На ней появится текст «начальная страница!!!».

Чтобы остановить сервер, вернись в терминал, где он запущен, и нажми CTRL+C.
