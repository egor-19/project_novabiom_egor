# Проект Novabiom

Учебное веб-приложение для учёта наборов на вымышленных данных.

## Что нужно для запуска

- Python 3.11 или новее
- Windows PowerShell для выполнения команд 

## Как запустить

Открыть PowerShell в папке проекта, где лежит app.py

1. Создать виртуальное окружение для проекта:
   ```
   py -m venv .venv
   ```
2. Установить зависимости из requirements.txt в это окружение:
   ```
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
3. Если запускаешь проект впервые и файла `novabiom.db` ещё нет, создай базу данных и таблицы:
   ```
   .\.venv\Scripts\python.exe uuu.py
   ```
4. Запусти локальный сервер Flask:
   ```
   .\.venv\Scripts\python.exe -m flask --app app.py run
    ```


## Как проверить

Открой в браузере страрицу по адресу: http://127.0.0.1:5000 
На ней появится текст «начальная страница!!!».

### Проверка создания набора

На новой базе открой http://127.0.0.1:5000/samples/new. Введи номер NB-1042 и вымышленное имя «Мария Иванова», затем нажми «Сохранить».

1. Открой http://127.0.0.1:5000/samples. В списке должен появиться NB-1042 со статусом issued («Выдан»).
2. Открой http://127.0.0.1:5000/samples/1. Если это первый набор в новой базе, ты увидишь его номер, имя клиента и статус.
3. Попробуй создать ещё один набор с номером nb-1042. Под полем номера должно появиться сообщение, что такой номер уже есть.

Чтобы остановить сервер, вернись в терминал, где он запущен, и нажми CTRL+C.
